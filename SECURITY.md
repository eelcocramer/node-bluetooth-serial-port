# Security Policy

## Supported Versions

Though this module is deprecated and no longer maintained I may fix security
issues for the current version.

| Version | Supported          |
| ------- | ------------------ |
| 3.0.x   | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

Security updates can be reported by opening an issue or by adding a vulnerability
disclosure.
